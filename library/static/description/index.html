Library Management

Gestión completa de biblioteca para Odoo 18

Módulo completo para la gestión de bibliotecas. Administra libros, autores, categorías y préstamos de manera eficiente.

Funcionalidades principales

  • Gestión de catálogo de libros con ISBN, portada y descripción
  • Directorio de autores con biografía y datos de contacto
  • Categorías para organizar el catálogo
  • Sistema de préstamos con flujo de estados (Borrador - Prestado - Devuelto)
  • Control automático de disponibilidad
  • Detección de préstamos vencidos
  • Vistas de lista, formulario, kanban y búsqueda avanzada
  • Integración con chatter para seguimiento de cambios
